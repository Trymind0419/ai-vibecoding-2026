# `pip freeze > requirements.txt` 명령어의 의미

이 명령어는 파이썬(Python) 프로젝트를 진행할 때 **"현재 내 컴퓨터(가상환경)에 설치된 모든 패키지의 정확한 버전을 기록해두는 작업"**을 의미합니다.

명령어의 각 부분을 쪼개서 설명해 드리겠습니다.

---

## 1. `pip freeze` 란? (freeze의 의미)
* **`pip`**: 파이썬 패키지 매니저입니다. (앱스토어 같은 역할)
* **`freeze`**: 영단어 그대로 **"얼리다"**, **"고정하다"**라는 뜻입니다.

`pip freeze`를 터미널에 입력하면, 현재 환경에 설치된 모든 파이썬 라이브러리(패키지)와 그 **정확한 버전 정보(스냅샷)**가 목록 형태로 출력됩니다. 마치 현재 상태를 그대로 꽁꽁 얼려서 박제해 두는 것과 같습니다.
*(출력 예시: `pandas==2.0.1`, `numpy==1.24.3`)*

## 2. `>` 란? (리다이렉션)
명령 프롬프트(터미널)에서 사용하는 기호로, **"왼쪽 명령어의 결과를 오른쪽 파일에 저장하라"**는 뜻입니다.

## 3. `requirements.txt` 란?
파이썬 생태계에서 설치된 패키지 목록을 적어두기로 약속한 **표준 텍스트 파일 이름**입니다. 꼭 이 이름이어야만 하는 것은 아니지만, 전 세계 파이썬 개발자들의 관례(Convention)입니다.

---

## 💡 요약 및 활용 (왜 이렇게 하나요?)
결론적으로 `pip freeze > requirements.txt`는 **"내가 지금 사용 중인 패키지 이름과 버전을 모조리 requirements.txt 파일에 적어서 저장해!"**라는 뜻입니다.

이렇게 만들어진 파일을 다른 컴퓨터나 팀원에게 주면, 그 사람은 아래 명령어로 **완전히 똑같은 환경을 단번에 구축**할 수 있습니다.
```bash
pip install -r requirements.txt
```
마치 요리 레시피(정확한 재료와 용량)를 적어두고, 다른 사람이 그 레시피대로 똑같은 요리를 만들 수 있게 해주는 것과 같습니다.
