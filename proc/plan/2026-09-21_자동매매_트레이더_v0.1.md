# 자동매매 트레이더 v0.1 구축 계획

## 목표
PRD v1.3.0 명세에 따라 가상 매매(Paper Trading)를 기본으로 실시간 시세 수집, 전략 시그널, 리스크 관리, SQLite 영구 저장 및 FastAPI 관제 인터페이스를 갖춘 자동매매 트레이더 v0.1 완성.

## 작업 항목
- [x] 1. 환경설정 및 DB 계층 구현 (`src/config.py`, `src/database.py`)
  - `.env` 설정 파싱 및 SQLite `data/trades.db` 테이블(`orders`, `executions`, `daily_snapshots`) 초기화
- [x] 2. 리스크 관리 모듈 구현 (`src/risk_manager.py`)
  - 단일 종목 투자 비중(20%), 일일 최대 손실(-2%), 스탑로스(-3%) 검증 로직
- [x] 3. 전략 엔진 구현 (`src/strategy.py`)
  - 변동성 돌파 전략(Volatility Breakout) 시그널 생성기 구현
- [x] 4. 오케스트레이터 봇 코어 구현 (`src/bot.py`)
  - 시세 조회 -> 전략 계산 -> 리스크 체크 -> 모드별(PAPER/LIVE) 주문 -> DB 기록 파이프라인 결합
- [x] 5. FastAPI 서버 통합 및 라우터 고도화 (`src/main.py`)
  - 봇 제어, 가상 잔고 초기화, 실시간 시세 조회, 수동 주문, DB 체결 내역 조회 엔드포인트 연동
- [x] 6. 의존성 정의 및 검증 테스트 (`requirements.txt`, 단위/통합 테스트)
  - 단위 테스트(`tests/test_v01.py`) 및 서버 라이프사이클/엔드포인트 통합 테스트(`tests/test_server.py`) 100% 통과 완료
