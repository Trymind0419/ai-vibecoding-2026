# [Plan] 구구단 프로그램 최적화

## 1. 목표
기존 `gugudan.py` 파일을 새 파일 생성 없이 수정하여 가독성, UI/UX, 예외 처리 및 성능을 최적화한다.

## 2. 최적화 항목
- [x] **전체 출력 레이아웃 최적화**: 2단~9단을 세로 나열 대신 4단 단위(2~5단, 6~9단) 가로 다단 테이블 형식으로 출력하여 한 화면에서 스크롤 없이 확인 가능하게 개선.
- [x] **단일 단 출력 UI 개선**: 박스형 서식으로 시각적 집중도 향상.
- [x] **사용자 편의성 및 예외 처리 강화**:
  - `q`, `exit` 등의 입력으로 즉시 종료 가능하도록 개선.
  - 음수/0/문자열 등 잘못된 입력에 대한 친절한 예외 메시지 제공.
  - Ctrl+C(KeyboardInterrupt) 안전 종료 처리.
- [x] **파일 반영**: 새 파일을 생성하지 않고 기존 파일(`gugudan.py` 및 `src/gugudan.py`)에 직접 반영.
