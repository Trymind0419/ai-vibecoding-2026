# SPARK Plan: 자동매매 DB 영구 보존 및 거래일지 구축

## 1. 개요
서버나 컴퓨터를 종료하면 가상 잔고, 보유 포지션, 체결 내역, 봇 로그가 모두 소실되는 문제를 해결하기 위해, SQLite(`data/trades.db`)를 기반으로 모든 매매 상태와 결과를 영구 저장하고 서버 재시작 시 자동 복원하는 데이터 파이프라인을 구축한다.

---

## 2. 작업 단계
- [ ] **1단계: 데이터베이스 모듈 전면 고도화 (`auto_trader/database.py`)**
  - `account_state`, `positions`, `orders`, `closed_trades`, `bot_logs` 테이블 스키마 초기화
  - 자산/포지션 CRUD 메서드, 주문 및 청산 거래일지 저장/조회, 누적 성과(승률, 실현손익) 집계 함수 구현
- [ ] **2단계: 트레이더 엔진 DB 영구 연동 (`auto_trader/nh_trader.py`)**
  - 트레이더 기동 시 DB에서 잔고(`paper_capital`), 보유 포지션(`paper_positions`), 최근 주문 내역 자동 로드
  - `order_buy()` 및 `order_sell()` 체결 시 DB에 자산, 포지션, 주문, 청산 내역 실시간 동기화
- [ ] **3단계: 자동매매 봇 DB 영구 연동 (`auto_trader/bot.py`)**
  - 봇 기동 시 이전 활동 로그 복원 및 기존 보유 종목의 고점(`highest_price`)을 로드하여 트레일링 스탑 유지
  - 신규 활동 로그 발생 시 DB `bot_logs`에 저장
- [ ] **4단계: 백엔드 API 신설 (`auto_trader/main.py`)**
  - `GET /api/v1/trades/history`: 최근 체결 내역 및 실현손익 청산 거래일지 반환
  - `GET /api/v1/trades/summary`: 총 실현손익, 승률, 총 거래건수, 평균수익률 집계 반환
  - `POST /api/v1/account/reset-paper`: 가상계좌 원클릭 초기화(원금 1,000만원 복원) API
- [ ] **5단계: 프론트엔드 대시보드 UI 연동 (`index.html`, `script.js`)**
  - 대시보드 우측 또는 하단에 "📊 누적 실현손익 & 거래일지" 패널 추가
  - 총 실현손익금, 승률, 거래건수 및 최근 청산 종목(익절/손절 내역) 실시간 표출
  - 가상계좌 초기화 버튼 제공
- [ ] **6단계: 통합 검증 테스트**
  - 매수 주문 발생 후 서버 프로세스 강제 종료 및 재가동
  - 잔고 차감 상태, 보유 종목, 주문 내역, 봇 로그가 100% 온전히 복원되는지 검증
