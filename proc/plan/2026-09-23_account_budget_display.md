# [작업 계획] 가상계좌 금액 및 추천 매매 금액 표시 기능 구현

## 1. 요구사항 분석
- **위치**: 나무증권 시세조회(Quote Board)와 가상 포트폴리오 사이
- **표시 내용**:
  1. **가상계좌 금액** (현재 가상계좌 잔고 / 향후 실거래 전환 시 나무증권 실거래계좌 금액으로 자동 전환되는 영역)
  2. **이번 추천에 사용할 금액** (1회 매수 추천 시 투입할 투자 예산)
- **모드 안내**: 현재 PAPER(모의투자) 모드임을 안내하고, LIVE 모드 전환 시 실거래계좌 금액으로 연동됨을 직관적으로 명시

## 2. 작업 단계 및 완료 내역
1. [x] **백엔드 API 확장 (`auto_trader/main.py`)**:
   - `/api/v1/account/budget` (GET, POST): 추천 사용 금액(기본 2,000,000원 또는 잔고 비율) 조회 및 설정 저장
   - `/api/v1/account/balance`: 계좌 유형(가상계좌/실거래계좌) 및 모드 정보 함께 반환
2. [x] **프론트엔드 UI 추가 (`auto_trader/static/index.html`)**:
   - 중앙 패널의 실시간 시세조회(Quote Board) 바로 아래에 `가상계좌 금액 & 이번 추천 매매 금액` 카드 컴포넌트 추가
   - 우측 패널의 명칭을 `가상 포트폴리오 (포지션 현황)`로 정돈하고 동일 지표 동기화
3. [x] **프론트엔드 인터랙션 (`auto_trader/static/script.js`)**:
   - 가상계좌 금액 실시간 반영
   - 이번 추천에 사용할 금액 표시 및 직접 입력/수정/비율(10%, 20%, 30%, 50%, 전액) 선택 기능
   - 수동 주문 시 [추천 예산으로 수량 자동계산] 원클릭 수량 계산 버튼 연동
4. [x] **스타일링 (`auto_trader/static/style.css`)**:

   - Obsidian Dark UI 테마에 맞춘 계좌 자산 카드 스타일
5. [x] **검증 및 화면 캡처**:
