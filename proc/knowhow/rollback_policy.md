# 롤백 및 작업 승인 정책 (Rollback & Approval Policy)

사용자의 명시적인 지시로 추가된 전역 작업 규칙입니다.

## 핵심 규칙
1. **사전 승인 필수**: AI는 파일 수정이나 주요 코드 변경 등 모든 작업 요청을 수행하기 전에, 무엇을 어떻게 바꿀지 사용자에게 먼저 제시하고 **사용자가 승인(commit)해야만 실제 적용(파일 쓰기/수정)**해야 합니다.
2. **원상복구(Rollback) 지원**: 사용자가 '돌려줘', '원상복구 해', 'rollback' 등을 요청하면 즉시 변경 사항을 취소하고 이전 상태로 완벽하게 되돌려야 합니다.
3. **백업 파일 생성 제한**: 롤백을 위한 대비책을 마련하되, **물리적인 백업 파일(.bak, .backup 등)은 사용자가 명시적으로 만들라고 지시할 때만 생성**합니다. 지시가 없을 때는 임시 변수나 메모리를 활용하여 롤백을 대비합니다.

4. **수정 범위 엄격 제한 (Untouchable 영역)**: 사용자가 명시적으로 수정하라고 지시한 파일이나 코드 영역 외에는 절대 임의로 건드리지 않습니다. 만약 시스템상 다른 파일의 수정이 불가피하게 필요하다면, **작업을 진행하기 전에 반드시 사용자에게 먼저 질문하여 허락(승인)을 구해야 합니다.**

5. **명령어 항시 제공**: 코드를 수정/업데이트할 때마다, 사용자가 서버를 재시작하거나 변경 사항을 확인할 수 있도록 **실행 명령어(예: uvicorn 실행 명령어)**를 매번 응답에 포함해야 합니다.
