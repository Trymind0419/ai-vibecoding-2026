# SPARK Spec: 자동매매 봇 실행 엔진 (Auto-Trading Engine) 명세서

## 1. 개요
사용자가 HTS 대시보드에서 `[자동매매 시작]` 버튼을 클릭했을 때, 단순 대기 루프가 아닌 **실제 시장 시세를 실시간 수집·분석하여 매수 조건(변동성 돌파) 만족 시 자동 매수 발주, 보유 종목의 익절(+3%) 및 손절(-2%) 조건 도달 시 자동 매도 발주**를 수행하는 지능형 자동매매 루프 엔진을 정의한다.

---

## 2. 매매 전략 및 의사결정 모델

### 2.1 진입 전략 (Entry: 변동성 돌파)
* **산출 수식**:
  $$\text{변동폭(Range)} = \text{당일 최고가(High)} - \text{당일 최저가(Low)}$$
  $$\text{매수 목표가(Target Price)} = \text{당일 시가(Open)} + (\text{Range} \times K)$$
  *(기본 $K = 0.5$)*
* **매수 신호 조건**:
  - `현재가(Current Price) >= 매수 목표가(Target Price)`
  - 해당 종목 미보유 상태 (중복 매수 방지)
  - 가용 예산 범위 내 1회 매수 집행 (최대 1종목당 예산 할당량)

### 2.2 청산 전략 (Exit: 익절 및 손절)
* **수익률 산출**:
  $$\text{수익률(PnL)} = \frac{\text{현재가} - \text{매입단가}}{\text{매입단가}}$$
* **자동 익절 (Take Profit)**:
  - `PnL >= +3.0%` (또는 전략 설정 익절선) 도달 시 전량 시장가/지정가 매도
* **자동 손절 (Stop Loss)**:
  - `PnL <= -MAX_LOSS_PCT` (기본 `-2.0%`) 도달 시 손실 확정 전량 매도

## 3. 실시간 활동 로그 브로드캐스트 (Live Log API)
* 봇의 활동 내역(감시 대상 종목, 가격, 목표가 비교, 매수/매도 발주 결과)을 메모리 큐에 보관
* `GET /api/v1/bot/logs` 엔드포인트를 제공하여 대시보드 화면 하단 터미널 콘솔에 실시간 출력
