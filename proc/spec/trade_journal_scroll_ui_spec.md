# SPARK Spec: 매매 결과 및 거래일지 스크롤 & 상세 카드 UI 개선

## 1. 개요 및 목적
- **목적**: 사용자가 우측 패널 하단의 "💾 매매 결과 & 거래일지 (DB 영구)" 영역에서 과거 청산 완료된 모든 매매 내역을 스크롤하여 직관적으로 확인.
- **주요 표시 항목**:
  1. **종목명 (메인 강조)**: 종목코드(005930) 대신 한글 기업명(삼성전자)을 메인으로 크고 굵게 표시.
  2. **매매 단가**: 매수가격 → 매도가격
  3. **수량**: 체결된 매도 수량
  4. **총금액**: 매도 체결 총액 (원)
  5. **수익률 or 손실률**: 실현손익(원) 및 손익률(%) 강조 (빨강: 익절 / 파랑: 손절)
  6. **근거 버튼**: 클릭 시 매수/매도 근거 팝업 모달 연동 유지.

---

## 2. UI 구조
- 컨테이너: `#closed-trades-list` (최대 높이 350px 확장 + 스무스 스크롤바 커스텀)
- 카드 레이아웃:
  - **상단**: `[기업명 (종목코드)]` + `[청산 사유 뱃지]` + `[근거 버튼]`  ──  `[실현손익금액 (+5,000원) (+2.50%)]`
  - **하단**: `매수 81,500원 → 매도 81,600원 | 68주`  ──  `총금액 5,548,800원 (체결시간)`
